圖片權利與隱私

TEAM / ID 是非官方球隊識別遊戲，與各聯盟、球團及品牌無隸屬或背書關係。

球隊名稱、商標、隊徽及球衣圖片的權利歸原權利人。網站程式不提供或暗示任何圖片再利用授權。網站發布者應確認使用權限。來源網址列於圖片清單、圖片報告及 PPT 備忘稿。

網站沒有帳號系統、廣告或第三方分析碼。手動匯入的圖片只保存於你使用的瀏覽器 IndexedDB，不會自動上傳到 GitHub或其他網站。瀏覽器快取用於保存已瀏覽的圖片；可從瀏覽器設定清除網站資料。

自動抓圖在網站發布者的 GitHub Actions 建置階段進行，不在玩家瀏覽時訪問外部商店。抓圖程式不使用外站登入帳密、不繞過驗證碼或付費限制。

如有圖片使用問題，請透過發布這個網站的 GitHub 儲存庫聯繫管理者。
